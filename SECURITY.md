# Security Policy

## Scope

FlyBit is a set of skills for Claude (plain-text instructions) and two Python scripts that run locally. The scripts use only the Python standard library and contain no network code. FlyBit does not send messages and does not collect data.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting: open the repository's Security tab and choose "Report a vulnerability". If that option is not available, use this contact: BRAK DANYCH

## Supported versions

BRAK DANYCH

## What to include

- the affected file or skill and the version (see `.claude-plugin/plugin.json`),
- steps to reproduce, and the expected and actual behavior.

Do not include customer data or personal data in a report.
